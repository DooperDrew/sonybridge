# 04 — UX

> Status: **APPROVED**

## Entry Points

### 1. Windows System Tray (Taskbar Notification Area)
- **Primary presence:** Lives silently in the system tray with a dynamic icon:
  - Connected: Headphone icon with mini battery bar overlay or tooltip: `WH-1000XM3 — 80% (ANC On)`.
  - Disconnected: Muted/greyed headphone icon with tooltip: `SonyBridge — Disconnected`.
- **Left-Click:** Opens the compact quick-flyout widget above the taskbar or reveals the main window.
- **Right-Click Context Menu:**
  - `WH-1000XM3 (80%)` [Status header, non-clickable]
  - `---`
  - `Noise Canceling` [Checked / Radio: On | Ambient Sound | Off]
  - `Quick Reconnect` [Action]
  - `Open Dashboard` [Action]
  - `---`
  - `Settings`
  - `Quit SonyBridge`

### 2. Main Dashboard Window
- Responsive, sleek window styled with a modern dark theme (accentuated with Sony's signature gold/copper accents matching the WH-1000XM3 hardware design).
- Accessible by clicking the tray icon or selecting "Open Dashboard".

### 2. Connection States & Feedback
- **Disconnected:** Displays friendly prompt: *"Sony WH-1000XM3 not detected. Make sure headphones are powered on and paired in Windows Settings."* with a prominent `[ Connect ]` button.
- **Connecting:** Subtle pulsing indicator: *"Establishing control channel over Bluetooth RFCOMM..."*
- **Connected:** Instant transition to active dashboard; battery level, active ANC mode, and EQ curves loaded directly from headset memory.
- **Error / Degraded:** Amber alert banner: *"Connected to Bluetooth, but control channel could not be opened. Click to run diagnostic probe."*

## First-Run / Onboarding Flow
1. App launches directly into the system tray and evaluates paired Windows Bluetooth devices.
2. If a Sony WH-1000XM3 (or compatible model) is already paired:
   - Immediately attempts to establish the RFCOMM control link.
   - Shows a subtle Windows toast notification: *"Connected to Sony WH-1000XM3 (Battery: 80%)"*.
3. If no paired Sony device is found:
   - Opens the onboarding window with instructions:
     1. Put headphones into pairing mode (hold power button for 7 seconds).
     2. Open Windows Bluetooth settings `[ Open Windows Settings ]`.
     3. Return to SonyBridge once paired.

---

## Behavior Rules
- **Instant Hardware Apply:** Sliders (Ambient Sound Level, EQ bands, Clear Bass) update the headphone hardware DSP in real-time with debounced packet transmission (75 ms debounce) to prevent Bluetooth buffer saturation.
- **Persistent Profile Storage:** Custom presets created in the UI are written to headphone hardware memory so they persist even when using the headphones with other devices.
- **DPI Scaling & Accessibility:**
  - High-DPI support on Windows 10/11 (100%, 125%, 150%, 200%).
  - Full keyboard navigability (Tab focus order, arrow keys for sliders, Space/Enter for toggles).
  - High-contrast compliance for text and UI sliders.
- **Localization:** All user-facing strings centralized in an i18n dictionary (`en-US` default, structured for easy community additions).
