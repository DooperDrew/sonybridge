# 04 — UX & System Tray Specification

> Status: **APPROVED & IMPLEMENTED (`v0.2.0`)**

## Entry Points

### 1. Windows System Tray (Taskbar Notification Area)
- **Primary presence:** Lives silently in the Windows 10/11 system tray.
- **Left-Click:** Instantly toggles the 3-tab SonyBridge flyout window (show/hide).
- **Right-Click Context Menu:**
  - `Sony WH-1000XM3` [Status header]
  - `Open Dashboard` [Restores window]
  - `Quick Reconnect` [Re-opens RFCOMM control channel]
  - `Quit SonyBridge` [Clean shutdown]

### 2. 3-Tab Adaptive Flyout Window
- Styled with a glassmorphic dark palette (`#0f172a` slate + `#38bdf8` cyan and `#f59e0b` Sony copper/gold accents).
- Top bar provides:
  - **Language Toggle (`EN` / `IT`)** for instant English/Italian switching.
  - **Onboarding Help (`?`)** to launch the 3-step First-Run Onboarding Wizard modal.
  - **Connect / Disconnect RFCOMM** action button.

---

## Screens & Flows

### Tab 1: 🎛️ Dashboard & EQ
1. **Device Telemetry Header:** Displays headphone model (`WH-1000XM3`), active RFCOMM service UUID badge, and live battery percentage bar.
2. **1-Click Sound Profiles Bar:**
   - **Focus (Max ANC)**
   - **Office / Calls**
   - **Cinema / Bass Boost**
   - **Studio Reference**
3. **Noise Canceling & Ambient Sound Card (`0x68`):**
   - 4-way segmented selector: **ANC On**, **Wind Reduction**, **Ambient Sound**, **Off**.
   - 20-step **Ambient Level** slider (`1..=20`) and **Focus on Voice** checkbox.
4. **Hardware 5-Band Equalizer & Clear Bass Card (`0x58`):**
   - Dedicated **Clear Bass** slider (`-10..+10`).
   - 5 vertical hardware DSP band sliders (`400 Hz`, `1 kHz`, `2.5 kHz`, `6.3 kHz`, `16 kHz`, `-10..+10 dB`) + **Flat (0 dB)** reset button.

### Tab 2: 🪟 Windows & Power
1. **Windows Audio Endpoint Sanitizer (`IPolicyConfig`):**
   - 1-click **Enforce High-Res Stereo (A2DP) Now** button.
   - **Auto-Switch A2DP on Connect** toggle.
2. **System & Headphone Power Settings:**
   - **Start with Windows (`HKCU\...\Run`)** toggle.
   - **Auto-Power Off (`0x28`)** dropdown (`5 min`, `30 min`, `1 hour`, `3 hours`, `Do not turn off`).
   - **Right-Ear Touch Sensor Panel (`0xD8`)** lock toggle.

### Tab 3: 🔬 Architecture & Wire Inspector
1. **Crate Separation Overview:** Summarizes `sonybridge-core` (`#![forbid(unsafe_code)]`) vs `sonybridge-windows` (WinRT RFCOMM + Core Audio COM).
2. **Live MDR v1 Wire Frame Inspector (`0x3E .. 0x3C`):**
   - Real-time hexadecimal log showing the exact byte-stuffed packet transmitted on every UI action, plus 1-click **Run RFCOMM Diagnostic Probe**.
